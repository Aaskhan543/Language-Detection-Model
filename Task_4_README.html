Project Overview

This module implements the Domain-Based Intelligent Voice AI Interviewer system. Designed as a structured, automated technical interview platform, the AI interacts with candidates using real-time Speech-to-Text and Text-to-Speech capabilities. It adapts dynamically based on the candidate's chosen domain and enforces strict enterprise interview protocols.

✨ Key Deliverables & Features

1. Domain Selection Routing
Candidates are presented with a UI modal to select their specific interview track (e.g., Frontend, Backend, Data Science, DevOps). The selected domain is passed seamlessly to the LLM, instantly adapting the AI's internal knowledge base and context prompt structure.
2. Master Interview Controller
The backend engine enforces a strict corporate interview format:
  • Fixed Format: The interview consists of exactly 5 questions, beginning with an introductory prompt.
  • Difficulty Scaling: The algorithm automatically ramps up the difficulty of questions from Easy to Medium to Hard/Expert as the session progresses.
3. Final Structured Evaluation
Upon completing the 5th question, the system automatically terminates the interview loop and generates a comprehensive, structured evaluation report featuring an overall score, identified strengths, areas for improvement, and a final hiring recommendation.

🧠 Architecture Details

  • app.py (The Switchboard): Flask routing engine that manages the HTTP payloads, triggers the TTS generation, and counts the interview interactions to enforce the 5-question limit.
  • llm_handler.py (The Brain): The integration point for the Groq API. It merges the user's selected domain into the system prompt, calculates difficulty scaling, and formulates the final summary.
  • memory_engine.py (The Context Store): A dynamic conversation tracker that feeds short-term history and long-term summaries back into the LLM to maintain conversational continuity.
